# 실행 증거 로그

`bash demo/run_demo.sh`가 각 단계를 실제로 돌려 그 출력을 그대로 저장한 파일들이다. 첫 줄은 실행한 명령, 둘째 줄은 시각과 커밋 해시.
(화면 스크린샷이 아니라 **텍스트 로그**다. git에서 diff·검색이 되고 다시 돌려 같은 결과가 나오는지 확인할 수 있어서 이 형식을 택했다.)

| 파일 | 무엇을 보여 주나 | 핵심 |
|---|---|---|
| `00_env.txt` | 실행 환경 | Python 3.12(컨테이너), 로컬 모델 `qwen2.5:7b-instruct` 4.7GB + `bge-m3` 1.2GB |
| `01_airgap_verify.txt` | 망분리 | 로컬 LLM 응답 OK, 외부 접속은 `Network is unreachable`(경로 자체가 없음) |
| `02_ingest.txt` | 인제스트 | 청크 116개(룰 88 + 머리설명 5 + 문서섹션 23), 벡터 1024차원 |
| `03_retrieval_eval.txt` | 검색 평가 | 벡터/BM25/하이브리드 비교, 질문 22개. 하이브리드 MRR 0.723 |
| `04_facts_check.txt` | 코드 계산 사실 점검(LLM 없음) | 15개 점검 전부 통과 |
| `05_ask.txt` | RAG 한 바퀴 | 질문 → 룰 100923 · 레벨 12 (원본 XML과 일치) |
| `06_triage_with_facts.txt` | 트리아지 (사실 포함) | 프롬프트 전문 포함 — LLM에 실제로 무엇을 보냈는지 |
| `07_triage_without_facts.txt` | 트리아지 (사실 없음) | 같은 알럿, 비교용 |
| `08_triage_false_positive.txt` | 오탐 사례(`GET /docs`) | 본문은 "정상 접근일 가능성"인데 판정 줄은 "보류" — 불일치 |
| `09_triage_eval.txt` | 트리아지 A/B 평가 12건 | 판정 정확도 8/12 vs 8/12 (오탐 0/4), 근거 언급만 개선 |

## 읽기 전에

- **로그의 커밋 해시는 `262536e`다.** 데모를 돌린 시점에 그 이후 코드(하이브리드 검색, `facts.py`, `triage_eval.py` 등)가 아직 커밋 전이라 작업 트리 상태로 실행했다. 이 로그들을 만든 코드는 이 로그를 포함한 커밋에 들어 있다.
- `09`는 데모와 별도로 먼저 백그라운드에서 돌린 출력이다(약 17분). 다시 만들려면 `bash demo/run_demo.sh --with-eval`.
- 로컬 LLM은 `temperature 0, seed 1`로 돌렸지만 CPU 추론이라 환경이 바뀌면 문구가 조금 달라질 수 있다. 검색 평가(`03`)·사실 점검(`04`)은 LLM이 없어 결정적이다.
- 평가 한계는 레포 `README.md`의 해당 절에 있다 — 특히 오탐 4건이 합성이고 코드 판정 12/12가 순환이라는 점.
